# ANP Việt Nam

Kho GitHub dành cho các tài liệu và công việc đã được chủ dự án cho phép lưu trữ của Project ANP Việt Nam.

## Hiệu lực nguồn

Tài liệu có trạng thái **DRAFT** hoặc **REVIEW** là bản đề xuất, không mặc nhiên được chủ Project phê duyệt hay trở thành nguồn chuẩn. Trạng thái **OWNER-APPROVED** đòi hỏi quyết định đúng phạm vi; **BASELINE** đòi hỏi xác nhận nguồn lưu có hiệu lực và bằng chứng đọc lại.

Các hồ sơ doanh nghiệp, hồ sơ tác giả, hệ chức năng, tiêu chuẩn đầu ra và vùng cấm giữ thẩm quyền theo lĩnh vực của mình. Lưu tài liệu vào repo không đồng nghĩa cấp quyền sửa website, xuất bản hoặc thay đổi production.
